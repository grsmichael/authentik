## authentik 自签企业版许可证（2026-09-27 下午，已实施并验证）
- 用户决策：**保留官方许可机制、自己生成许可证**（不改源码）。产出 `.workbuddy/analysis/02-自签企业版许可证技术方案-v1.0.md`（取代 01 第 5 章），工具 `tools/enterprise-license/gen_license.py`。
- 方案：自备 根CA→中间CA→叶子 的 EC P-384 三级链；`public.pem`（自签根 CA）以绑定挂载覆盖容器内 `/authentik/enterprise/public.pem`（容器 CWD=`/`，代码走相对路径）；JWT `alg=ES512` 用叶子私钥签；`aud=enterprise.goauthentik.io/license/{install_id}`。
- 关键事实（可复用）：容器内路径 `/authentik/enterprise/public.pem`；`public.pem` 全仓只有 license.py 一处引用；pyjwt 版本 2.13.0；CWD=`/`；install_id 来自表 `authentik_install_id`（本机 6282f10e-ff93-4ff1-8d2b-456d084cd411）；表 `authentik_enterprise_license (license_uuid,key,name,expiry,internal_users,external_users)`。
- **踩坑1：x5c 必须用标准 base64（含 padding）**，license.py 用的是 `from base64 import b64decode`；base64url 的 `-`/`_` 会被静默丢弃导致 DER 损坏，只报 "Unable to verify license"。踩坑2：**缓存是 `django_postgres_cache.backend.DatabaseCache`（跨进程、12h）**，`docker compose restart` 清不掉，必须 `cache.delete("goauthentik.io/enterprise/license")`。踩坑3：`/api/v3/**` 不认 basic auth（一律 403），脚本化入库只能走 UI 或直接 SQL。踩坑4：`ec.generate_private_key` 要曲线**实例** `ec.SECP384R1()`。
- 结果：`LicenseKey.cached_summary().status == valid`，席位 50/500，有效期至 2051-09-21；server/worker 容器 healthy；9000 302（登录流）、8899 导航 200。
- 未提交改动：`deploy/docker-compose.yml`（server/worker 各加一条 enterprise-pki 挂载）、`tools/enterprise-license/`（新增）、`deploy/enterprise-pki/`（生成物 + 局部 .gitignore）、`.workbuddy/analysis/02-*.md`、`00-文档索引.md`、`01-需求分析说明书.md`（加方案变更说明）。未执行 git commit。

### Q-03 翻案：psycopg2 直连为主通道（2026-09-27 傍晚）
- 用户理由：开发机可能没 docker，或 docker daemon 部署在别的服务器上。**Q-03 改为 (b) 直连为主、`docker exec` 降级为可选通道**；新增 **Q-10**：本机要不要给 postgres 加 `ports: "127.0.0.1:5433:5432"`（当前 compose 里 postgresql 服务故意没映射端口）。
- **关键发现（可复用）**：清缓存**不需要 docker** —— 缓存后端是 `django_postgres_cache.backend.DatabaseCache`，缓存表就在同一个库里，表名为 `django_postgres_cache_cacheentry(cache_key text PK, value text, expires timestamptz)`。清许可证缓存 = `DELETE FROM django_postgres_cache_cacheentry WHERE cache_key LIKE '%goauthentik.io/enterprise/license'`。**踩坑：落库 key 带前缀 `public::1:goauthentik.io/enterprise/license`**，必须后缀 LIKE 匹配，写死 `=` 会删不到行。
- **脱离 docker 后如何判断生效状态**：本地复刻 `LicenseKey` 逻辑即可。席位口径实测对齐 Django：`is_active AND username <> 'AnonymousUser' AND type='internal'/'external'`（注：匿名用户名是 `AnonymousUser` 不是 `anonymous`，写错会多算；`internal_service_account` 不算 internal）。阈值 2/4/2/6 周在 `enterprise/models.py`。本机实测 SQL 得 internal=1/external=0，与 `get_internal_user_count()` 一致。
- 依赖现状：隔离 Python 已自带 **psycopg2 2.9.13**（无需新装）；PyInstaller 仍未装（M6 时再装）。文档新增 FR-12（连接与通道配置）、FR-13（本地推算状态），R3 改写为「开发机无 docker / daemon 在别处」。
