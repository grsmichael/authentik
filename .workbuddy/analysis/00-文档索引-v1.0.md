## 一、文档目标

围绕一个明确问题展开：**authentik（本仓库，版本 2026.11.0-rc1）哪些功能被企业版（Enterprise, EE）许可卡住、社区版是否真能用、以及"个人自用"场景下如何把这些限制去掉**。

产出一篇需求分析说明书（01），作为后续开发的唯一输入；开发按 01 的章节编号推进，每完成一步回写 01 的状态列。

## 二、读者

- 本次改动的使用者/决策者（个人自用、非生产）
- 后续执行改动的开发（按 01 第 5 章的补丁落点实施）

## 三、术语

| 术语 | 含义 |
|---|---|
| CE | Community Edition，社区版，AGPL-3.0 开源，可自由部署 |
| EE / Enterprise | 企业版，按席位授权，**功能代码与 CE 在同一个代码库**，靠运行时许可校验区分 |
| License Key | 一张企业版许可 JWT，`aud = enterprise.goauthentik.io/license/{install_id}`，由 Authentik Security 用离线私钥签名 |
| install_id | 实例唯一标识，`get_unique_identifier()` 生成，写死在首次运行的环境里（`authentik/tenants/utils.py`） |
| LicenseSummary | 许可状态汇总（internal/external 用户数 + status + flags），缓存 12 小时 |
| LicenseUsageStatus | 状态枚举：Unlicensed / Valid / ExpirySoon / Expired / LimitExceededAdmin / LimitExceededUser / ReadOnly |
| 硬阻断 | 服务端 API 直接 400/404 拒绝；社区版 **一定**创建不出来 |
| 前端隐藏 | 服务端未校验，只是 UI 不渲染（可直调 API 绕过） |
| 条件阻断 | 仅在某些配置组合下拦截（如 RADIUS 配 EAP-TLS 证书、SCIM 选 OAuth 模式） |
